# cguard 配图 · 设计基调

## 目的

GitHub README 首屏和社交分享用图。读者多数是**小白**：他们不看架构，只想知道
「这东西能让我 C 盘多出多少空间」和「我的电脑能不能用」。

因此优先级：

1. **效果**（30 GB → 142 GB）必须是第一眼看到的东西
2. **元凶**（谁吃掉的）让人产生「对，就是我」的代入感
3. **可信**（有数字、有来源、不吹牛）建立信任
4. 用法与架构放在第二眼

## 视觉方向

**深色石墨 + 单一强调色**。理由：开发者工具的默认语境是深色终端；深色背景在
GitHub 亮/暗两种主题下都不会刺眼；避免「AI 味」的紫蓝渐变。

| token    | 值        | 用途          |
| -------- | --------- | ------------- |
| `bg`     | `#0A0E13` | 底色          |
| `panel`  | `#121A23` | 卡片          |
| `line`   | `#1F2B3A` | 分隔线        |
| `fg`     | `#E9F0F7` | 主文字        |
| `dim`    | `#8FA2B7` | 次要文字      |
| `danger` | `#FF6B5A` | 占用 / 清理前 |
| `ok`     | `#35D399` | 释放 / 清理后 |
| `brand`  | `#58A6FF` | 品牌 / 命令行 |

红绿在此**不表示涨跌**，表示「危险 / 安全」，全世界的磁盘工具都这么用，不套用
A 股红涨绿跌。

## 禁止

- 不用 emoji（技术文档里显廉价，且跨平台渲染不一致）
- 不用 AI 生图写中文（必然出现错字，必须代码绘制）
- 不虚标数字：所有数字来自本机实测或仓库里的真实记录
- 不超过 3 张主图，README 里堆图会拖慢加载
